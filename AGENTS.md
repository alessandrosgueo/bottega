# Istruzioni per gli agenti

Questo repo è la bottega stessa e lavora col suo metodo. Prima di ogni lavoro leggi la costituzione del repo,
`docs/costituzione.md`: dice dove si lavora, come si lanciano le prove, lo stile e cosa non si tocca. Il metodo è in
`plugin/skills/bottega/SKILL.md`.

- Niente di personale nei file: il repo diventerà pubblico.
- Niente commit sul ramo principale, niente unioni.
- Se una scelta contraddice il piano, è irreversibile o tocca segreti o dati veri, fermati e chiedi con
  `DOMANDA PER CHI DECIDE:`.
